# Who’s Driving

Кооперативная игра от первого лица про автомобильные погони на Unreal Engine 5.8. Проект находится в разработке.

В текущем прототипе есть управление автомобилем на Chaos Vehicles, четыре места с пересадкой, высовывание из окон и стрельба. У каждого игрока своё основное и второстепенное оружие. Занятость мест, расход патронов, попадания и урон обрабатывает сервер.

## Запуск

Для разработки нужны Windows, Unreal Engine 5.8, Visual Studio 2022 с инструментами C++ для Unreal Engine и Git LFS. Компоненты Visual Studio перечислены в [Whos_Driving/.vsconfig](Whos_Driving/.vsconfig).

1. Клонируйте репозиторий и загрузите бинарные ассеты:

   ```powershell
   git lfs install
   git lfs pull
   ```

2. Через контекстное меню `Whos_Driving/Whos_Driving.uproject` выберите **Generate Visual Studio project files**.
3. Откройте созданное решение, выберите **Development Editor / Win64** и соберите проект `Whos_Driving`.
4. Откройте `Whos_Driving/Whos_Driving.uproject` в Unreal Editor. Для проверки игровой механики используйте уровень `/Game/FirstPerson/Lvl_FirstPerson`.

Для локальной сетевой проверки в настройках Play выберите **Play As Listen Server**, включите **Run Under One Process** и задайте число игроков.

## Управление

| Клавиша | Действие |
| --- | --- |
| F | Взаимодействие с местом, на которое смотрит игрок |
| H | Выход из машины; во время пересадки — её отмена |
| 1 / 2 | Основное / второстепенное оружие |
| Левая кнопка мыши | Стрельба |
| Правая кнопка мыши | Прицеливание |
| R | Перезарядка |
| V | Смена режима огня |
| Q | На левых местах — высунуться, на правых — вернуться в салон |
| E | На правых местах — высунуться, на левых — вернуться в салон |

Пассажиры могут стрелять только из окна. Водитель в салоне использует второстепенное оружие. Высунувшись, он может использовать основное, но теряет возможность рулить; машина сохраняет последнее значение газа. При возвращении водитель переключается на второстепенное оружие. Пешая стрельба пока отключена.

## Структура

- `Whos_Driving/Source` — игровой C++ код и модуль инструментов редактора.
- `Whos_Driving/Content` — карты, Blueprint, модели, материалы, анимации и звуки.
- `Whos_Driving/Config` — настройки проекта.

Модели оружия, звуки и часть анимаций взяты из M8s Stylized Shooter Kit. Анимации персонажа перенесены на Manny.
